# 安装与首次使用

1. 解压本 ZIP，找到本文件所在目录（同级有 manifest.json）。
2. Chrome 打开 chrome://extensions/，Edge 打开 edge://extensions/。
3. 开启“开发者模式”，选择“加载已解压的扩展程序”，选择本目录。
4. 登录 B 站，停用旧油猴脚本，刷新收藏夹页面。
5. 点击工具栏扩展图标，或收藏夹页右下角“整理收藏夹 ↗”。
6. 在管理页点击“连接并读取列表”，点击名称查看，勾选或鼠标拖动框选加入整理；拖至列表上下边缘会自动滚动，Ctrl / ⌘ 拖动反选，Esc 取消本次框选。搜索后“全选筛选结果”仅作用于当前结果，生成预览才读取视频。
7. 检查规则、分配和目标可见性，明确确认后才开始移动。

执行时保持管理页打开。取消执行前的确认不会刷新或写入。

当前版本：1.4.0。请先用少量专门的测试收藏验证登录、创建、移动与顺序。

## 1.4.0 命名继承与批量恢复

- “整理规则 → 收藏夹命名”可选择按左侧来源列表顺序继承名称。新旧数量相同时，新夹用原名、旧夹追加“旧”；新夹较少时只继承前面的名字，所有旧夹不改名；新夹较多时前面的继承，多出的用配置名称与序号，旧夹追加“旧”。默认仍使用配置的基础名称。
- 预览和确认显示全部新名称与旧夹改名；冲突编号、超长缩短均提前显示。旧夹可见性、简介和封面保留，新夹使用当前可见性配置。响应不明确时停止，不重试或自动撤销改名。
- 临时批量异常经核对后允许有限度重新探测；真实单条上限继续遵守。校正只重建有误前缀，保留完整核对过的正确后缀。请求仍保持 1.2 秒串行间隔。

## 当前验证边界

- 代码与模拟集成测试通过；云 Chromium 管理策略禁止自定义扩展，未在这里完成真实 Chrome / Edge 实装和真实账号验证。
- 已启用执行时验证的自适应批量；先 2 条探测，顺利时扩大至 20、100 条。不支持时核对后降级，仍保留限流停止。模拟提速不代表 B 站实测耗时。
- 使用配置名称时，预览会为同名目标添加编号；非视频收藏会停止并说明。跨源重复视频只移动按左侧列表顺序的第一份有效副本，其余留在各自原夹，预览显示保留数量。失效视频单独计数、保留在原夹，不阻断其余视频整理，不自动删除。没有自动合并收藏夹、回滚或断点恢复。
- 加速或校正可能额外创建一个私密中转夹，确认弹窗会说明。成功后保留空夹，可自行删除；中断时请核对源、目标、中转三处，勿删除仍有视频的中转夹。
- 只把设置和冷却时间保存在本机，不保存或导出登录 Cookie / CSRF。

## 1.3.4 目标全量核对与耗时

- “核对目标的所有分页”现在逐页显示条数、百分比与页数；多个目标连续核对时保留已完成的目标进度。中转与校正时的分页读取也显示进度。
- 已用时每秒刷新：1327 秒显示为“22 分 7 秒”，3661 秒显示为“1 小时 1 分 1 秒”；完成或停止后不继续计时。

## 1.3.3 读取与核对进度

- 预览读取、执行前核对、执行后来源检查均显示毛玻璃双进度卡片：整体按收藏夹计算，当前收藏夹显示准确条数、百分比及已读取页数。
- 执行前收起尚未开始的移动统计，核对后恢复；失败保留停止进度，缓存重算不模拟读取，支持窄窗口和减少动态效果设置。

## 1.3.2 整理可靠性

- 以视频实际读取结果核对来源，不因目录数量滞后误拦或误报完成；显示为空的来源也实际核对。
- 自定义命名预览自动避开已有收藏夹重名，并在确认时显示实际名称；确认后的新同名冲突仍会阻止执行。
- 检查新目标为空、目标 / 中转 ID 未复用；创建接口明确拒绝访问权限时不反复更换表单重试。
- 97 项自动化检查包含 2,000 组异常组合，另跑实际页面模拟浏览器检查。测试不使用真实 B 站账号，无法保证服务端限流、网络及接口行为。

## 1.3.1 重复视频与框选

- 重复视频不再阻断预览；每个视频只移动一份，其余来源保留。预览、确认及完成状态显示重复记录保留数量。
- 执行前核对所有所选来源，结束时按“视频 + 来源”核对；允许其他来源的副本保留，同时识别指定来源未移出的异常。

- 新增目录框选与上下边缘自动滚动，保留筛选外选择；松开后保存，取消时恢复。窄窗口面板同样支持，触屏直接滑动与勾选，任务中禁止修改范围。
- 采用前景毛玻璃、中性背景和完整文字操作，窄窗口的收藏夹目录与规则可分别展开。
- 同账号当前页持续保留来源缓存，读取与预览没有固定过期时限；修改规则或移除再选回可复用，新增来源只读缺失部分。
- 确认执行后先重新读取全部来源，核对 ID、失效状态和排序信息；发现变化则在写入前停止。此阶段随记录数增加而延长，仍保留 1.2 秒请求间隔。
- 失效条目显示数量与所在来源，不参与分组和容量计算；全是失效内容时仅提供只读预览。
- 提交与完整核对分开显示；完成后同步目录，停止时提供位置与冷却说明。
- 更新前结束任务，替换文件后在扩展管理页重新加载，再关闭旧管理页并重新打开。
