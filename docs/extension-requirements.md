## 可配置规则

| 规则 | 默认 | 建议可选项及约束 |
| --- | --- | --- |
| 按 UP 主聚合 | 开启 | 可关闭；关闭后全体视频按时间排序并按容量拆分 |
| UP 主排列 | 按视频数量从多到少 | 数量从少到多、按 UP 主名称；聚合关闭时禁用 |
| 同一 UP 主不拆分 | 开启 | 可关闭，允许跨目标收藏夹拆分；关闭聚合时此项禁用 |
| 视频发布时间 | 降序，最新在前 | 升序，最早在前；聚合开启时在各 UP 内排序，关闭时对全体排序 |
| 每个目标容量 | 1000（沿用原脚本） | 整数 1–1000；保持不拆分时，单 UP 超过容量须提高容量或显式允许拆分，不暗中改变规则 |
| 目标基础名称 | UP聚合 | 可自定义，多个目标自动增加序号，并遵守平台长度限制 |
| 目标可见性 | 私密 | 可选公开；执行前确认框明确展示公开 / 私密 |

缺失发布时间时，沿用原脚本的确定性兜底逻辑；正式实现需明确缺失日期项的排序位置，并使预览与实际结果一致。首次打开管理页不自动全量扫描。

默认容量沿用原脚本的 1000，用户可以自行改小。

## 核心流程及取消行为

工具栏图标 / B 站页内控件 → 独立管理页 → 选择与规则 → 读取并生成预览 → 返回调整或确认执行 → 当前页显示进度和必要完成 / 错误提示。

- 取消最终确认：零创建 / 移动请求、零刷新，预览立即恢复可操作。
- 修改规则后重算：复用同一份有效快照，不反复全量读取。
- 写入后：当前预览失效，避免把执行前数据当作实时状态再执行。
- 出现限流：停止后续请求，显示已处理与未执行状态及冷却提示；不自动不断重试。
- 执行时保持管理页打开。可以切换标签页；不承诺关闭页面 / 浏览器后的继续运行或恢复。
- 第一版仍为“移动”，不新增复制模式。

## UI 方向与原型

[新版可点击原型](extension-prototype.html)是完全本地的示例，不连接 B 站，不代表已实现的扩展或实测速度。

截图：[桌面设置页](extension-ui-desktop.png) · [分组预览页](extension-ui-preview.png) · [窄屏布局](extension-ui-mobile.png)。

| 旧原型 | 新设计 | 原因 |
| --- | --- | --- |
| 粉色主调、较重卡片强调 | 雾灰 / 白色 / 蓝色系统控件 | 匹配用户要求的克制、精细视觉 |
| 规则固定在说明文字中 | 明确开关、下拉选择及时间分段控件 | 让规则可见、可改，禁用关系清楚 |
| 侧栏备份、独立结果页 | 预览核对与原页执行状态 | 移除用户不需要的功能，减少步骤 |

- 以 #F5F5F7 雾灰背景、白色面板、#1D1D1F 主文字、#0069D2 蓝色主操作构成轻量工作空间。
- 桌面使用窄侧栏、顶部状态栏、左右设置面板；收窄后折叠为单列。
- 系统字体、细分隔线、轻阴影和一致圆角；不使用苹果标志、专有图标或外链字体。
- 发布时间采用“最新在前 / 最早在前”分段控件；开关、禁用状态、键盘焦点和错误提示可见。
- 预览中可展开前几条视频的顺序，方便核对升降序；执行状态直接嵌入预览。
- 删除旧版粉色主调、备份区和结果页，不添加用户已删除的导出动作。
- 原型同时展示两个入口的示意，以及完成 / 限流 / 网络失败状态，所有进度均为模拟。

本轮 Chromium 原型检查通过：默认 6000 条示例分组、时间升降序、UP 数量排列、聚合 / 拆分切换、公开确认、缓存复用、取消 / Esc、说明页往返、完成 / 限流状态、容量错误、搜索选择及窄屏溢出检查。检查期间无外部请求；这不是 Chrome / Edge 扩展或真实移动接口的验收。

## 性能方案与验证边界

详细方案见 [移动性能分析](extension-performance.md)。

当前脚本逐条请求，6000 条在至少 1.2 秒间隔下，仅移动请求开始跨度约为 7198.8 秒（约 2 小时），还未计入读取、网络和重试。现有额外 350ms 等待与全局间隔有重叠，不能将两者简单相加估算全部任务。

优化目标是减少可合并的移动请求，不提高无约束并发。1.1.0 在执行时从小批量探测并校正展示方向，逐步扩大批次；跨源交错时可用一个私密中转夹汇总，再按全局顺序写入目标。每个请求仍限定来源与目标，最终全量核对。明确拒绝时核对归属后降低批次，不稳定时逐条校正；限流 / 超时即停，不以近似顺序换速度。确认弹窗说明中转行为，成功保留空夹，中断保留内容供核对，不自动删除。
