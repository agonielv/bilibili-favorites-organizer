# Installation

Source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill

Installed with the official `ui-ux-pro-max-cli` v2.15.0 using `uipro init --ai codex --offline` into this project. Scripts use Python 3 standard library. MIT license is included in `LICENSE`. The skill and its data are development tools and are excluded from extension packages.
